### Terminal2D is an open-source terminal-based engine. It is NOT made for practicality or long-term usage. Please credit the original creator (redhairedidiot on GitHub) when redistributing.

## Terminal2D works best in computer programs like VSCode. Here is a startup guide for using Terminal2D in VSCode:

### Step 1: Install the .NET SDK
  Get the .NET SDK from Microsoft at this link: `https://dotnet.microsoft.com/en-us/download `.

### Step 2: Get VSCode (Visual Studio Code)
  Get Visual Studio Code and install it at this link: `https://code.visualstudio.com/thank-you?dv=win64user&build=stable`.

### Step 3: Install needed extensions
  After installing VSCode, get the C# Dev Kit & C# Extensions if you haven't already. Both extensions are made by `Microsoft`.

### Step 4: Import Terminal2D (If all steps worked correctly)
  After all steps are done, you can reload your developer window then import Terminal2D.
  Go to `File` -> `Open Folder` and create a new folder (or open a folder you wish to use).
  Once the folder was opened, in your File Explorer or Finder (or whatever your operating system may utilize) and drag Terminal2D.cs into your folder.

### Step 5: Create a CSPROJ
  First, trust your folder. If you look in the bottom left and see a blue text with: `Restricted Mode` showing, click it and press `Trust` on the next page.
  Open a new terminal by going to `Terminal` -> `New Terminal`. Select the first option (if any line asks for one).
  Type in the following command: `dotnet new console`. Make sure the folder is trusted!
  Delete the new `Program.cs` file that was created-if you wish.

### Step 6: Utilize the Manual .zip folder
  Download the `Manual.zip` from this repository, and read the texts inside for further instruction.
